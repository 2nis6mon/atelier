## Atelier 1.0.0 — macOS (Apple Silicon)

**Download:** `Atelier-1.0.0-arm64-mac.dmg` (or the `.zip`). Requires a Mac with Apple Silicon (M1 or later) and macOS 13 Ventura or later.

**Signature status:** ad-hoc signed, **not** signed with an Apple Developer ID and **not notarized** (no Apple developer account was available). macOS will ask you to confirm the first launch — see *First launch* in `docs/INSTALL.md`. Gatekeeper is never disabled globally.

- Everything is stored on your Mac: library, CVs, original documents, applications, versions and sent files.
- AI is optional and runs only when you ask: ChatGPT (sign-in), OpenAI API, Claude API or a local model. No key is bundled.
- No telemetry.

The installer in this draft was built and tested by CI on an Apple Silicon macOS runner (see the workflow run for the full test report, coverage and screenshots).
